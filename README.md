# SpiderWeb 蛛网语义响应场

SpiderWeb 是一项面向长文档理解的探索性研究。它从一个问题出发：阅读一篇长文档时，能否根据提问激活相关的局部内容，再定位和核验证据？研究手册给出概念与公式，R2 系列记录首跳证据定位实验。

## 研究问题

最初的想法是先掌握长文档的主干，再按提问回查细节。当前构想进一步让问题参与证据候选的形成。手册描述了从问题表示、文档响应、候选区域到证据核验和局部处理的过程。如果候选证据存在冲突或支持不足，可以继续更新候选区域。完整框架的实现与验证仍待研究。

## 首跳证据定位实验

R2 实验考察模型能否从候选中优先选出第一步所需的证据。其中两项研究各进行了一次独立验收。第 10 批获得 61.98% 的首跳准确率，较池化对照高 0.22 个百分点，低于预设的 5 个百分点门槛。第 13 项按另一协议运行，准确率为 55.01%，低于同候选池化和直接取首位两项对照。历次协议、正负结果和相关条件均收入总表。[查看第 01 至 16 批总表](%E5%AE%9E%E9%AA%8C/%E7%AC%AC01%E8%87%B316%E6%89%B9%E5%88%86%E7%89%88%E6%9C%AC%E6%80%BB%E8%A1%A8.txt)
