## 在本地阅读 HTML 报告

从仓库的 **Code → Download ZIP** 下载并解压，在相应资料目录中双击 `打开资料.html`。在 GitHub 点开 `.html` 可以查看文件，完整排版由本地浏览器呈现。报告和图形可离线查看，跳转外部文献需要联网。
